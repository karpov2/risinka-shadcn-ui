# MessageScroller

A chat scroll container that anchors turns, opens saved transcripts, follows streamed responses, loads history without jumping, and jumps to any message. Файл — `src/components/ui/message-scroller.tsx`, документация — https://ui.shadcn.com/docs/components/base/message-scroller.
